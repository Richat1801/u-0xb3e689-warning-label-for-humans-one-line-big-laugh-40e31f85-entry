# Warning Label for Humans: One Line, Big Laugh

Entry for the [make.fun bounty](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

`main.ts` (Node 22, stdlib only, deterministic) holds a bank of 10 original warning labels, scores each against the judge's published criteria — label wording, recognition, turn landing in the last few words, economy — and writes only the winner to `/output/entry.txt`.

Winner (98 characters):

> WARNING: This human contains 60% water, 30% caffeine, and 10% absolutely no idea what it is doing.

Run it with `node main.ts`. The output is byte-identical across runs.
